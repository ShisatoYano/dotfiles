# PR優先度判定基準

`pr-task-planning`の「自分が出したPRの一覧・優先度整理」から参照される、優先度判定の観点。

- `reviewDecision`(`--review approved`などの分類の元)は「必須承認数を満たしたか」しか見ていないため、一部のレビュアーがコメントのみで承認していない状態でも`approved`に分類されうる点に注意する
- 判定順: CI失敗中 → 変更要求あり → 一部レビュアーがコメントのみ・未回答のまま止まっているもの(実質レビュー未完了) → (様子見)レビュー待ち → 全員承認済み
- draft PRは参考として別枠で扱う
