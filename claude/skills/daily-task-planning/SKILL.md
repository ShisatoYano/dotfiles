# Daily Task Planning

Notionの担当タスクと、PR対応・レビュー(`pr-workflow` Skill)を合わせて、その日の作業リストを決める。

## 前提

- Notionタスクのプロパティ構成・`見積`の人日換算は`notion-task-workflow` Skillの前提を参照する
- PR対応は先に時間を確保し、残りをNotionタスクの予算にする

## 手順

1. その日の総稼働予算(人日)をユーザーに確認する。指定がなければ1.0人日をデフォルトとする(会議等で稼働時間は日によって変わるため、固定値にしない)
2. サブワークフロー1(PR/レビュー計画)を実行し、対応が必要なPR/レビュー項目とその見積を得る
3. 総稼働予算から2の見積合計を差し引き、残りをサブワークフロー2(Notionタスク計画)の予算とする
4. サブワークフロー2(Notionタスク計画)を、3で求めた予算で実行し、Notionタスク候補を得る
5. 2のPR/レビュー項目と4のNotionタスク候補を合わせた候補リストをユーザーに提示し、着手済みタスクの扱いやIssueタスクの優先度、PR対応の見積など状況に応じた入れ替えを含めて確認・調整を受ける。確定したリストがその日の作業対象になる

## サブワークフロー1: PR/レビュー計画(pr-task-planning)

`pr-workflow`が扱うのはレビュー・承認・コメントなど軽微な作業が中心で、レビュー指摘に伴う修正作業そのものはここに含めず別途Notionタスクとして扱う。そのため、ここでの見積もりは基本的に合計1時間以内(人日換算で0.125人日程度)を目安とする。見積もりがこれを大きく超える場合は、その旨をユーザーに確認する。

1. `pr-workflow` Skillの「自分が出したPRのワークフロー」「自分にアサインされたレビューのワークフロー」それぞれのステップ1(一覧・優先度整理)を実行し、対応が必要なPR/レビュー項目を取得する
2. 取得したPR/レビュー項目それぞれについて、対応にかかりそうな時間(人日換算)をユーザーに確認する

## サブワークフロー2: Notionタスク計画(notion-task-planning)

指定された予算(人日)に収まるところまでNotionタスクを選定する。

1. `nb search --path` などで`work` notebook(`notion-task-workflow` Skillが書き出す)内の直近の`daily/*.md`を確認し、前日までの持ち越し・未完了タスクがあれば把握する
2. 自分の未完了タスクの一覧を取得する。ユーザーが用意した「自分のタスク」ビューがあればそれを`query_data_sources`(view mode)で取得する。無ければ、タスクDBを`担当者`に自分を含む条件で検索する
3. `担当者`が複数人いるタスクは、`見積`をそのまま自分の工数として使わない(見積はタスク全体の工数で、自分の持ち分ではないため)。該当タスクは都度、今日実際に割く時間をユーザーに確認し、その値を4以降で使う
4. 各タスクの`見積`(3で確認した複数担当者タスクは確認済みの時間)を人日換算し、以下の目安で並び替えの一次案を作る(機械的な絶対順位ではなく判断材料として扱う):
   - `ステータス`が`Doing`(着手済み)のタスクは基本的に他より優先するが、絶対ではない
   - 次点は以下の2グループを**同格**として扱う(どちらかを機械的に優先しない): (a) `期限`があるタスクを期限昇順・優先度順に並べたもの、(b) `期限`が未設定でも`種類`が`Issue (Fix)`かつ`優先度`が`Highest`のタスク
   - 上記以外(期限なし・Issueでもない)は優先度順で最後に並べる
5. 4の一次案から、見積(人日換算)の累計が指定された予算に収まるところまでを候補としてリストアップする
