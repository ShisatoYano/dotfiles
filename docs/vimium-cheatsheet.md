# Vimium C(ブラウザのVimキーバインド拡張) チートシート

ChromeでVimライクな操作を行う拡張機能のキーバインドをまとめたもの。
元は本家Vimiumを使っていたが、Notionでのスクロール不具合([philc/vimium#4517](https://github.com/philc/vimium/issues/4517))を
きっかけにVimium Cへ切り替えた。キーマッピングの記法に互換性があるため、
`vimium/custom-key-mappings.txt`の内容はそのまま移行できている(下表の★印がカスタマイズ箇所)。

## タブ操作
| キー | 動作 |
|---|---|
| `H`★ | 前のタブへ(nvimのバッファ切り替え`S-h`=前と同じ指癖) |
| `L`★ | 次のタブへ(nvimのバッファ切り替え`S-l`=次と同じ指癖) |
| `x` | 現在のタブを閉じる(weztermの`leader+x`=ペインを閉じる、nvimの`<leader>x`=スプリットを閉じるに合わせた「x=閉じる」の感覚) |
| `X` | 直前に閉じたタブを復元 |
| `t` | 新規タブ |
| `J` / `K`, `gt` / `gT` | デフォルトのタブ切り替えキー(`H`/`L`と併用可、unmapはしていない) |

デフォルトでは`H`/`L`はブラウザ履歴の戻る/進むだった。それを`h`/`l`側に
移動させ、空いた`H`/`L`をnvimのバッファ切り替えと同じキーに寄せている(下記参照)。

## 履歴・スクロール
| キー | 動作 |
|---|---|
| `h`★ | ブラウザ履歴を戻る(デフォルトの`H`から移動) |
| `l`★ | ブラウザ履歴を進む(デフォルトの`L`から移動) |
| `j` / `k` | 下/上にスクロール(デフォルトのまま) |
| `d` / `u` | 半ページ 下/上 スクロール(weztermの`leader+d`/`leader+u`と同じキー・同じ意味) |
| `gg` / `G` | ページの先頭/末尾へ |

左右スクロール(デフォルトの`h`/`l`)は使用頻度が低いため、戻る/進むに明け渡した。
左右スクロールが必要な場合は`zH`/`zL`(ページ端まで一気にスクロール)を使う。

## リンク・URL操作(デフォルトのまま)
| キー | 動作 |
|---|---|
| `f` | リンクヒントを表示し、現在のタブで開く |
| `F` | リンクヒントを表示し、新規タブで開く |
| `i` | 強制的にinsertモードへ入る(自動認識されない入力欄を手動でフォーカスしたいとき用。`Esc`で抜ける) |
| `r` | ページをリロード |
| `gi` | 最初の入力欄にフォーカス |
| `gu` / `gU` | URLを1階層/ルートまで遡る |
| `ge` / `gE` | 現在のURLを編集(`gE`は新規タブで開く) |
